できること

打刻と勤怠

出勤・退勤・休憩の確認、スタッフ本人の勤怠の修正と申告、修正の履歴（元の打刻は残ります）。PIN は任意（4 桁以上）。

シフトと申請

シフトの作成・公開、遅刻・早退・欠勤の検出、早出・残業の申請と管理者の確認。シフトを基準にした給与の対象時間。

給与

時給（曜日・時間帯別）・月給、割増、交通費・手当・控除（手入力）、給与の確定・訂正、明細（PDF）。有給休暇の管理。

人件費

日・曜日・時間帯・スタッフ別の人件費の分析、予算と実績・着地の予測。CSV・Excel の出力。

権限と安全

管理者パスワード、スタッフごとの個別の権限、ほかのスタッフの給与・個人情報を見られない設計、監査ログ。

バックアップ

毎日の自動バックアップと手動のバックアップ。データの復元・更新は、安全のため Google 所有者の保守作業として手順書に沿って行います。

はじめ方（共通 Setup）

  1. 共通 Shiftly Setup の URL を開き、店舗の Google アカウントを選んで、Google の確認画面で権限の内容を確認して許可します。
  2. 「Google Apps Script API がオフ」と表示された場合は、案内に従って Google の設定画面でオンにし、「設定が完了したので再確認」を押します（Google の仕様で、1 回だけ必要です）。
  3. 構築先のアカウント・作成するもの・保存先を確認し、店舗名を入力して開始します。あなたの Google アカウントの中に、Shiftly が自動で作られます。
  4. 途中で表示されるボタンから、Shiftly 本体と管理画面の権限を Google の画面で許可します。
  5. 完了画面から管理者パスワードを設定し、店舗端末の登録コードを発行して、iPad で QR コードを読み取ります。

Google Cloud の設定やプログラムの貼り付けは不要です。共通 Setup は現在、開発者が登録した検証用のアカウントだけが使える限定公開の準備中で、Google の実際の環境での動作の確認を終えてから案内します。審査が終わるまでは「このアプリは Google で確認されていません」と表示されます。提供者から直接 URL を受け取った場合以外は進まないでください。

データの扱い

保存先

  • 勤怠・給与・スタッフの情報は、店舗の Google ドライブの「Shiftly」フォルダのデータベース（スプレッドシート）だけに保存します。
  • 提供者（開発者）の Google ドライブやサーバーには保存しません。
  • このページとデモは、業務データを受け取りません。

アクセスの範囲

  • Shiftly は、Shiftly が作成したファイルだけを操作する権限を使います（Google ドライブ全体は読みません）。
  • Google のパスワードを Shiftly が受け取ることはありません。
  • 店舗の iPad は Google にログインせずに使います。

現在の状態

  • v1.3.0 は限定先行運用版です。本番の導入の後、少なくとも 1 給与計算期間は、紙のタイムカードと従来の給与計算を並行して使い、結果を照合してください。
  • Google の実際の環境・iPad の実機での動作確認は、公開の前の必須の検証としてこれから行います（自動テストは模擬の環境で合格）。
  • 対応する労働時間制度は通常の労働時間制だけです。税・社会保険料は手入力です。法令の解釈を含む細部は専門家への確認が必要です。

Shiftly（シフトリー）— 店舗の勤怠・シフト・給与・人件費の管理。デモは架空のデータだけで動き、Google には接続しません。

導入・運用の手順は、リポジトリの docs/installer-guide.md・docs/operations-guide.md にあります。
