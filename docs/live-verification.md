## 1.6 初めて Google Apps Script（GAS）を扱う人のための構築手順

手順は docs/installer-guide.md「0.5 初めて GAS を使う方へ」と同じです（本番の導入と共通にしました）。検証では次の点だけが異なります。
- **検証用の Google アカウント**（本番の管理者アカウント・会社のアカウントではない）を使い、実在のスタッフの氏名・PIN・給与を入力しない（架空のデータだけ）
- 配布物は、GitHub Release ができる前は PR の CI の Artifacts「shiftly-gas-bundle」（保存期間 14 日）、Release の後は Release の `shiftly-gas-bundle.zip` を使う
- 途中で止まった・エラーが出た場合は、画面のメッセージの全文（スクリーンショット）を控え、**自分で Drive のファイルやプロジェクトを消さずに**開発者に共有する
