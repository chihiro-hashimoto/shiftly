# テスト計画・結果

## 1. テストの種類

| 種類 | 場所 | 実行 | 内容 |
|---|---|---|---|
| 単体 | tests/unit | `npm run test` | 日時・期間、勤怠の状態遷移と再構築、有給、暗号（PBKDF2/SHA-256/HMAC を Node・RFC ベクタと照合）、CSV/XLSX（openpyxl で読込確認）、**給与ゴールデン（手計算の独立期待値）** |
| 統合 | tests/integration | `npm run test:integration` | Core API の業務フロー、Setup 状態機械（擬似 Apps Script API）、**ビルド済み GAS バンドルのエミュレーション実行**（要 build:gas） |
| セキュリティ | tests/security | `npm run test:security` | 全 op の未認証拒否、店長専用 op、失効端末・期限切れセッション、PIN 総当たり（個人・端末単位）、IDOR、権限変更の即時反映、自己昇格・なりすまし、ステップアップ、個人給与の推定防止、出力制御、署名の改ざん・期限切れ・リプレイ、エラー情報漏えい、監査ログへの秘密情報混入 |
| E2E | tests/e2e | `npm run test:e2e` | プレビュー（モック Core）上で Kiosk（打刻・誤PIN・休憩中退勤・本人画面・タブ非表示・タップ領域・横スクロール・委任メニュー）、Setup。iPad 横/縦・PC 1440・スマホ 390 |

給与計算の期待値は実装関数の出力を使わず、仕様書（docs/payroll-specification.md）から手計算した数値リテラル（式をコメントに記載）。作成は実装ロジックを読まない担当が行った。

## 2. 網羅状況（主な観点）

| 観点 | 状態 |
|---|---|
| 22時・0時・5時境界、日付またぎ、法定休日またぎ | 自動テスト済み |
| 日次・週次（40h）・月60時間超、日次と週次の重複防止、期間をまたぐ週 | 自動テスト済み |
| 週 44 時間（特例フラグ） | 実装済み・**ゴールデンテスト未作成** |
| 個人別・曜日別・時間帯別・時給変更・重複ルール | 自動テスト済み |
| 月給制・法定内残業・固定残業代（不足・超過）・欠勤/遅刻早退控除 | 自動テスト済み（欠勤控除は統合テストで規定未設定時の拒否のみ） |
| 最低賃金、未設定条件、控除なし/未入力、確定・訂正・過去確定の維持 | 自動テスト済み |
| 端数処理（期間合計で 1 回、half_up / ceil） | 自動テスト済み |
| 有給（付与・比例付与・取得・FIFO・時効・年 5 日） | 自動テスト済み |
| 同時操作 | **単一スレッドのモックでは真の並行実行を再現できない**。設計（スクリプトロック内で読み込み→検証→書き込み）とジャーナル再適用で担保。GAS 実環境での並行テストは未実施 |
| 途中失敗からの復旧（ジャーナル） | 自動テスト済み（書き込み失敗の注入） |
| バックアップ・復元（復元後の打刻保持・端末失効維持・セッション失効） | 自動テスト済み |
| セットアップ重複実行・中断再開・既存環境検出・アカウント取り違え・改ざん検知 | 自動テスト済み（擬似 API） |
| 更新・マイグレーション・ロールバック | 自動テスト済み（擬似 API・マイグレーション定義は空） |
| 管理画面の各ページ | 実装担当が Playwright で手動操作を確認（E2E としての自動化は Kiosk/Setup のみ） |
| アクセシビリティ | タップ領域・ラベル・キーボードフォーカス表示を確認。axe 等の自動監査ツールは未導入 |
| WebKit / iPad 実機 | **未実施**（Chromium のデバイスエミュレーションのみ） |
| Google 実環境 | **未実施**（docs/technical-verification.md §4） |
