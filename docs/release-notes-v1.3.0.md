> 版: 1.3.0（`package.json`・`APP_VERSION`）。対象のコミット・配布物の SHA-256 は GitHub Release に記載します（リリースの作成時に記入。**未作成**）。
> **限定先行運用版**です。本番の環境の構築の後、少なくとも 1 給与計算期間は、紙のタイムカードと従来の給与計算を並行して使い、結果を照合してください。Shiftly だけで勤怠・給与を管理する正式な運用への切替は、照合の結果と必須の実環境検証に基づいて、別途判断します。

## 1. 概要

Shiftly は、店舗の勤怠・シフト・給与・人件費を、店舗の Google アカウントの中（Google Apps Script・Google スプレッドシート・Google ドライブ）だけで管理する Web アプリです。月額の費用はかかりません（Google の無料の範囲で動作する設計。課金の登録を求められた場合は作業を止めてください）。

- **Shiftly-Staff**: 共用の店舗 iPad の画面（打刻・本人の勤怠の確認と修正・シフト・明細）と、業務データを更新する唯一の経路
- **Shiftly-Admin**: Google 所有者の管理画面（PC）。店舗 iPad の「管理者ページ」からも、管理者パスワードで管理者モードに入れます
- **Shiftly Setup**: 初回の自動構築（Staff・Admin の作成・配置・デプロイ、Google ドライブのフォルダと DB の作成）

## 2. 提供する機能（初回リリース対象 37・一部手動 2）

共用 iPad での店舗運用／管理者パスワードの認証／スタッフの PIN（任意）／個別の権限／出退勤の打刻／勤怠の修正と修正の履歴（原本は不変）／休憩の確認／シフト管理／シフト基準の給与計算／早出・残業の申請と確認／時給・月給／交通費・手当・控除／給与の確定・訂正・明細（PDF）／有給休暇／通知／人件費の分析・予算／CSV・XLSX の出力／Google アカウントの連携／GAS・DB の初回の自動構築／自動・手動のバックアップ／監査ログ

一部手動: **F26** バックアップは自動・手動、データの復元は Google 所有者の保守作業／**F35** 初回の DB 構造の生成は自動、版の更新に伴う DB の移行は延期（docs/requirements.md「v1.3 のリリース範囲」）

## 4. 方針（B案: 正常時は自動・異常時は手動）

日常の業務・初回の構築・バックアップは自動です。障害時の復旧・データの復元・アプリの更新は、Google 所有者が手順書に従って手で行います（docs/decisions.md D-027）。安全に戻せることが確認できない場合は、業務を止めて（紙のタイムカード）開発者に相談します。

## 5. 延期した機能（v1.3.0 では提供しない。実装済みとして数えない）

アプリ内の自動復元／稼働中の DB の自動切替／自動アップデート／更新に伴う DB の自動移行／自動ロールバック／障害時の複雑な自動復旧（**F36**・**F37**、F26 の自動復元、F35 の更新部分）。これらの処理は配布物に含まれず、どの経路から呼ばれてもサーバーが拒否します。

## 6. 既知の制約

- 対応する労働時間制度は通常の労働時間制だけ（変形労働時間制・フレックスタイム制は確定できない）。税・社会保険料は手入力（自動計算・年末調整はしない）
- 法令の解釈を含む細部（法定休日をまたぐ勤務など）は**要専門家確認**（docs/payroll-specification.md）
- 管理画面から、管理者が過去の勤務の「予定休憩を取得した」を申告する画面はない（休憩は「休憩を追加」で登録する。スタッフは iPad で申告できる）
- 保守作業の照合は DB の行が対象（Google ドライブの PDF・出力・バックアップのファイルは対象外）。セルの数式は検出するが、計算結果が数式の文字列と同じになる特殊な数式は見分けられない
- 保守作業の実行時間（GAS の 6 分の上限）は未計測
- Codex 独立監査は累計 24 回。24 回目の判定は「マージ不可」で、その後の B案による仕様変更・修正について**独立した再監査による合格は取得していません**

## 9. 今後の更新

- 修正版は別のブランチ・別の PR で作り、ユーザーの承認の後に main へ反映し、GitHub Release で配布します
- 環境への反映は docs/update-rollback.md「2 公開後の手動アップデート」（Google 所有者の保守作業。DB の構造が変わらない修正版だけ。**最初の修正版の前に L31 で検証**）
