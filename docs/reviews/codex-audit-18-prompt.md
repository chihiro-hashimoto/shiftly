## マージの意味（判定の前提）
- main へのマージは「本番デプロイ」や「本番運用の開始」ではありません。マージ後も、本番利用の前に実環境の検証と、紙のタイムカードとの並行運用が必要です（docs/operations-guide.md）
- ただし main は今後の配布物（Setup に同梱する GAS のコード）の基準になります。初回の構築から日常の運用（打刻・申請・給与計算・バックアップと復元）で、重大な害（賃金の未払い・過少計算、個人情報・給与の漏えい、権限昇格、データの消失・破損）が起き得る問題が残っていないかを重視してください

- マージ後・本番利用の前に必要な事項（実環境の検証など）は、マージの可否とは分けて最後に箇条書きで
- コード読解だけでの判断や、実行していない検証は、その旨を明記
- スタイル・好み・軽微な改善は書かない
