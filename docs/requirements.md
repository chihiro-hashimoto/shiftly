# 要件（統合マスタープロンプト v1.2 ＋ 追加仕様変更 v1.3 の要点）

> 正式な指示は統合マスタープロンプト v1.2（2026-11-24）と追加仕様変更指示 v1.3（2026-11-25）。v1.3 で変更した部分は v1.3 を優先し、それ以外の v1.2 の確定済み要件・F01〜F37・安全ルールは維持する。本書は再入力なしで作業を継続するための要約。

## 製品
- Shiftly（シフトリー）: 店舗勤怠・給与・シフト・人件費管理 Web アプリ。日本語、Asia/Tokyo、JPY
- 対象: ダーツバー・飲食店 1 店舗、スタッフ 10 名以下、曜日で営業時間が異なり深夜 0 時をまたぐ勤務あり、現状は紙のタイムカード
- 端末: 店舗共用 iPad 1 台でスタッフ操作と管理者操作を完結（v1.3。縦横対応、オフライン打刻は対象外）。管理者の PC・スマホからの利用（Shiftly-Admin、Google 認証）も維持するが、別端末を通常運用の必須条件としない
- 雇用: 時給・月給混在、個人別・曜日・時間帯別時給、休憩は予定休憩（標準）・打刻・手動を併用、交通費は個人別、控除は手動入力、締め日・支払日は設定可、通知はアプリ内のみ
- 認証: Google 所有者は Google（全権限・構築/更新/復旧/管理者パスワードの設定）、店舗 iPad の管理者は管理者パスワード（v1.3）、スタッフは氏名選択＋個別 PIN（v1.3: PIN は任意）、スタッフ単位の権限、共用 iPad に Google ログインを残さない

## 必須条件（無断変更禁止）
月額無料／Supabase・Cloudflare Pages・有料サーバー/DB/API 不使用／GAS バックエンド／Sheets を DB／Drive をストレージ／管理者本人の Google アカウント内／初回に Google 連携／GAS・DB・フォルダの自動構築／業務データを端末へ永続保存しない（端末認証情報のみ可）／キャッシュクリアでクラウドデータが消えない／管理者 Drive の無関係なファイル保護／スタッフへ Drive 直接共有しない／サーバー側で認証・権限検証／GitHub は Private 維持／実データ・認証情報を GitHub・AI 環境に保存しない／本番と開発・テストの分離

F01 初期設定・DB自動生成 / F02 店舗端末 / F03 管理者・スタッフ認証 / F04 個別権限 / F05 スタッフ・雇用条件 / F06 打刻 / F07 休憩 / F08 勤務時間・勤怠確認 / F09 勤怠修正・履歴 / F10 シフト / F11 遅刻・早退・欠勤検出 / F12 時給管理 / F13 月給制 / F14 給与計算 / F15 交通費 / F16 手当 / F17 控除 / F18 給与締め・確定・訂正 / F19 給与明細 PDF・本人閲覧 / F20 有給 / F21 アプリ内通知 / F22 人件費分析 / F23 予算・予測 / F24 CSV・Excel / F25 監査ログ / F26 バックアップ・復元 / F27 店舗設定 / F28 Google 連携 / F29 初期セットアップウィザード / F30 GAS 自動生成 / F31 GAS コード自動配置 / F32 GAS 自動デプロイ / F33 既存環境検出 / F34 中断・再開 / F35 DB 構造の自動更新 / F36 アプリアップデート / F37 ロールバック・環境復旧

## v1.3 の変更（2026-11-25）
| 項目 | 内容 | 実装 |
|---|---|---|
| 用語 | Kiosk→Staff、店長→管理者（画面・文書・コード・GAS プロジェクト名 Shiftly-Staff）。互換に必要な旧識別子は内部のみ（docs/decisions.md D-014） | 全体 |
| 1 台の iPad | Staff 画面右上「管理者ページ」→ 管理者パスワード → 管理者モード。無操作 5 分・ログアウトで失効、重要操作は再認証 | F38 |
| PIN 任意 | PIN 未設定は氏名選択のみで出退勤（本人未確認）。給与・明細・勤怠詳細は非表示、修正・申請は承認待ち。PIN は 4〜12 桁（先頭 0 可） | F03 拡張 |
| 本人の勤怠修正 | 出勤・退勤・打刻漏れ・休憩を本人が修正。原本は不変、修正履歴・本人確認の有無・管理者の確認を保持 | F39 |
| 時給ルールの導線 | 「スタッフ・権限」の各スタッフに「時給ルール」「月給設定」。独立したナビゲーションは廃止 | F05/F12 |
| 休憩 | 予定休憩を初期値とし、退勤時に取得状況を確認（休憩ボタンは標準で非表示）。予定休憩は取得を確認したものだけ控除 | F07 拡張 |
| シフト基準の給与 | 公開シフトを基準。シフト外の時間は実労働と確認したものだけ加算。未確認があれば確定不可 | F41・F14 拡張 |
| 早出・残業申請 | 申請・承認・一部承認・差戻し・却下・取消・確認済み。承認状態と実労働の確認を区別 | F40 |

追加機能 ID（既存 ID は流用しない）: **F38** 店舗 iPad の管理者モード（管理者パスワード）／ **F39** スタッフ本人の勤怠修正・休憩の申告／ **F40** 早出・残業申請と管理者確認／ **F41** シフト基準の給与対象時間とシフト外勤務の確認

## 対象外
スタッフからのシフト希望提出、自動シフト生成、税・社会保険料率からの自動計算、年末調整、メール/LINE 等の外部通知、オフライン打刻

## 承認が必要な事項
本番デプロイ、main へのマージ、実在スタッフの登録、正式な給与支払いへの利用、有料サービス、外部公開、データ破壊・不可逆変更、給与規定など管理者しか知らない情報、Codex 監査 6 回目以降

## 未確定事項（設定画面・導入手順で後から登録。架空の確定値を使わない）
iPad 機種/OS、Drive 空き容量、曜日別営業時間、営業日の切替時刻、労働時間制度、週 40/44 時間、法定休日、週の起算日、36 協定、月給制の規定、固定残業代、個別時給、曜日・時間帯別時給、交通費規定、各種手当、締め日・支払日、電子明細の交付条件、過去の有給残日数、紙タイムカードの移行範囲

> 注: 週 44 時間特例は「常時 10 人未満」が要件。「スタッフ 10 名以下」は 10 名の場合に要件を満たさないため、自動適用しない（管理者が確認してフラグを設定）。
