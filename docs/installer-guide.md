# 導入手順（Shiftly Setup）

> **本番導入はユーザー（管理者）の承認後に実施**します。まず検証用の Google アカウントで試すことを推奨します。

## 0. 必要なもの

- 管理者の Google アカウント（2 段階認証を推奨）
- PC（Chrome / Edge / Safari）
- 店舗の iPad（Safari）
- 事前準備: `docs/google-api-setup.md`（Apps Script API をオン、Setup 用 Cloud プロジェクト）

## 1. Setup の配置（どちらか一方）

### A. 自己ホスト（推奨）— 管理者アカウントに Setup を置く

**clasp を使う場合（開発者が代行）**
```bash
npm ci
```
```bash
npm run build && npm run build:gas
```
```bash
cd dist/gas/setup && npx @google/clasp create --type webapp --title "Shiftly Setup" && npx @google/clasp push
```
（clasp は管理者アカウントでログインした端末で実行。clasp のログイン情報 `.clasprc.json` はリポジトリにコミットしない）

**ブラウザのみの場合**
1. https://script.google.com/ で「新しいプロジェクト」を作成し、名前を「Shiftly Setup」にする
2. 「プロジェクトの設定」→「appsscript.json をエディタで表示」をオン
3. `dist/gas/setup/` の各ファイルを同名で作成して内容を貼り付け: `appsscript.json`, `Code.gs`（= Code.js）, `Release.gs`（= Release.js）, HTML ファイル `setup`（= setup.html）
4. Cloud プロジェクトの紐づけ（google-api-setup.md §2-5）
5. 「デプロイ」→「新しいデプロイ」→ 種類: ウェブアプリ、実行: 自分、アクセス: 自分のみ → デプロイ

### B. ホスト型 — 配布者のアカウントで公開

`dist/gas/setup/appsscript.hosted.json.txt` を appsscript.json として使い（実行: アクセスしているユーザー、アクセス: Google アカウントを持つ全員）、配布者がデプロイして URL を管理者に渡します。Setup のコードは管理者の権限で動くため、**配布者を信頼できる場合のみ**利用してください。

## 2. セットアップの実行

1. Setup の URL を管理者の Google アカウントで開き、権限を確認して承認
2. 店舗名を入力し「セットアップを開始」
3. 自動工程: アカウント確認 → API 確認 → Shiftly-Staff 作成・コード配置・デプロイ
4. **管理者の操作①**: 「スクリプトエディタを開く」→ 関数 `shiftlyAuthorize` を選んで「実行」→ 権限を確認して許可（Shiftly が作成したファイルのみ操作する権限）→ Setup に戻り「確認して続行」
   - このとき Google ドライブに `Shiftly/`（00_System〜05_Backup）とデータベースが作成され、日次トリガーが登録されます
5. 自動工程: Shiftly-Admin 作成・配置・デプロイ
6. **管理者の操作②**: Admin のエディタで `shiftlyAuthorize` を実行 → 許可 → 「確認して続行」
7. 自動工程: 更新用の接続設定 → 接続・DB 整合性の確認 → 完了
8. 完了画面に表示される **管理者用 URL**（Google 所有者の PC 用。ブックマーク）と **店舗 iPad 用 URL（Shiftly-Staff）の QR コード**を控える

途中で画面を閉じても、次回 Setup を開くと続きから再開します。進捗は Google 側（UserProperties と Drive のレジストリファイル）に保存され、端末には保存しません。

## 3. 初期設定（管理画面）

1. 「システム・更新」: **管理者パスワードを設定**（12 文字以上。店舗 iPad の「管理者ページ」に入るためのパスワード。Google 所有者の画面でのみ設定・再設定できます）
2. 「店舗設定」: 営業時間、営業日の切替時刻、労働時間制度、週の起算曜日、法定休日、締め日・支払日、最低賃金（公式資料で確認した額と根拠）、有給の賃金算定方法、**勤怠・給与の時間基準（標準: シフト基準・予定休憩）** 等 → 「給与規定の確認」
3. 「スタッフ・権限」: スタッフ登録、PIN 設定（任意）、必要なら個別権限と管理用パスコード、各スタッフの「時給ルール」「月給設定」で時給・月給・交通費・手当・雇用条件
4. 「店舗端末」: 登録コードを発行

2〜4 は、iPad を登録した後に店舗 iPad の「管理者ページ」（管理者モード）からも行えます。

## 4. 店舗 iPad の登録

1. iPad の Safari で店舗 iPad 用 URL（Shiftly-Staff。QR）を開く
2. 共有メニューから「ホーム画面に追加」
3. 管理者が発行した登録コードを入力
4. **Google アカウントで iPad にログインしないでください**（店舗 iPad 用 URL はログイン不要。管理者は右上の「管理者ページ」から管理者パスワードで操作します）

## 5. トラブルシューティング

| 表示 | 原因・対処 |
|---|---|
| Apps Script API が無効です | script.google.com/home/usersettings で API をオン。Setup の Cloud プロジェクトでも API を有効化 |
| 別の Google アカウントで作成されています | 管理者のアカウントでログインし直す（取り違え防止） |
| 配布ファイルの検証に失敗 | Setup を正規の配布物で更新 |
| Shiftly-Staff に接続できません | `shiftlyAuthorize` を実行したか確認 |
| `shiftlyAuthorize` が「前回の…の作成の結果を確認できません」で止まる | 前回の実行でフォルダ・DB・環境情報ファイルの作成の結果が分からなかった（D-026 S1）。数分おいて `shiftlyAuthorize` を再実行（作成済みなら検索に反映されて使われる）。Google ドライブに該当のフォルダ・ファイルがないこと（またはゴミ箱に移動したこと）を確認した場合は、エディタで `shiftlyConfirmStorageNotCreated` を実行してから `shiftlyAuthorize` を再実行（確認の操作は検索し直し、見つかったものはそのまま使い、見つからないものだけを作り直す） |
| `shiftlyAuthorize` が「…が 2 つあります」で止まる | 同じ構成物が二重に作られた可能性。Google ドライブの Shiftly フォルダで、使わないほうをゴミ箱に移動してから再実行（自動では選ばない・削除しない） |
| Setup が「記録している…を確認できませんでした」と表示する | 記録しているプロジェクト・デプロイを照会で確かめられなかった（一時的な失敗の可能性）。数分おいて再実行。Apps Script の画面で見つかった場合は「既存の ID を関連付ける」に ID を入力。削除したことを確認した場合だけ、チェックを付けて再実行（作り直す） |
| 開始時に「Setup の記録が見つかりません」と表示される | Setup の記録（UserProperties・Google ドライブの「Shiftly Setup Registry.json」）が見つからない。以前にこのアカウントで構築した場合は、記録ファイルがゴミ箱にないか確認して元に戻し、再読み込みする。初めての構築の場合だけ、確認のチェックを付けて実行（D-026） |
| 完了画面の「自動では確認していない項目」 | Apps Script のプロジェクト一覧で「Shiftly-Staff (環境ID)」「Shiftly-Admin (環境ID)」が 1 つずつであることを確認する（Setup の権限ではプロジェクトを一覧できないため）。2 つ以上ある場合は、削除せずに管理者に相談する |
| Setup が「作成結果を確認できませんでした」「デプロイを確認できませんでした」と表示し、確認のチェックを求める | 画面の案内どおり、Apps Script のプロジェクト一覧・「デプロイを管理」で確認する。ない（または整理した）ことを確認した場合だけ、チェックを付けて再実行（二重作成の防止。D-025 S1） |
| 作成途中で通信が切れた | Setup を開き直して「続きから実行」。同名（環境 ID 付き）のプロジェクトが二重にある場合、レジストリに記録されていない方は手動で削除可 |
| iPad が「登録されていません」 | Safari のデータ消去等で端末トークンが消えた可能性。管理画面で新しい登録コードを発行して再登録（業務データは消えていません） |
