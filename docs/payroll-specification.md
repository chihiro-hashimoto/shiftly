# 給与計算仕様（Shiftly）

> 本書は実装（`src/shared/payroll.ts` / `labor.ts` / `wage.ts` / `attendance.ts`）の仕様である。
> 法令解釈を含む箇所は **「要専門家確認」** と明記する。実際の給与規定は本番利用前に店長および必要に応じて社会保険労務士等が確認すること。
> 法令の根拠は `docs/research/official-sources.md`（公式ドメインの検索結果に基づく。原文の再確認が必要）を参照。

## 1. 前提と対応範囲

| 項目 | 対応 |
|---|---|
| 労働時間制度 | **通常の労働時間制のみ**。変形労働時間制・フレックスタイム制を選択した場合は計算は表示するが **正式確定を禁止**（通常制へ暗黙にフォールバックしない） |
| 週の法定労働時間 | 40時間。週44時間特例は店長が要件（常時10人未満・対象業種）を確認しフラグを立てた場合のみ。人数条件から自動適用しない |
| 36協定 | 記録のみ。未締結でも実労働時間・割増賃金は削減しない（情報として表示） |
| 計算単位 | 打刻はサーバー時刻（秒単位に切捨てて記録）。労働時間は **秒単位** で計算し、日々の切捨ては行わない |
| 端数処理 | 金額は有理数（BigInt 分数）で積算し、**項目ごとの期間合計で1回だけ** 円未満処理（既定: 50銭以上切上げ。設定で「切上げ」も可）。控除（欠勤・遅刻早退）は労働者に不利にならないよう円未満切捨て。30分単位の時間丸めは行わない |
| 法令ルールのバージョン | `LEGAL_RULESETS`（適用開始日付き）。現行 `JP-LSA-2023-04`: 時間外25%／月60h超50%／法定休日35%／深夜25% |

## 2. 日時の区別

| 概念 | 定義 | 用途 |
|---|---|---|
| 打刻日時 | サーバー受信時刻（UTC epoch ms、表示は Asia/Tokyo） | 原本 |
| 営業日 | 打刻時刻 −「営業日切替時刻」（既定 05:00）の暦日 | 表示・集計・時給ルールの曜日/祝日/時間帯判定 |
| 労働日 | **始業時刻（出勤打刻）の暦日**。日付をまたぐ連続勤務は始業日に属する | 1日8時間判定・週判定・給与期間への帰属 |
| 法定休日 | 店舗設定の曜日の **暦日 0:00〜24:00** | 休日労働判定 |
| 週 | 店舗設定の起算曜日から7日（労働日で判定） | 週40時間判定 |
| 給与計算期間 | 締め日設定から算出。労働日が期間内の勤務を当期に計上 | 支給 |

## 3. 労働時間の区分アルゴリズム（`classifyLabor`）

1. 各勤務（退勤済み）の実労働区間（休憩を除く）を、暦日 0:00・5:00・22:00、時給ルールの時間帯境界、営業日境界で分割して「piece」にする。
2. piece の暦日が法定休日の曜日なら **法定休日労働**。（法定休日前日からの勤務が0時を越えた部分は休日労働、法定休日から翌日に越えた部分は休日労働ではない）
3. **1日単位の時間外**: 法定休日労働を除く piece を労働日ごとに時系列で累計し、8時間を超えた時刻以降。
4. **週単位の時間外**: 法定休日労働・1日単位の時間外を除く piece を週ごとに時系列で累計し、40時間（特例44時間）を超えた時刻以降（日次と週次の二重計上なし）。
5. **月60時間超**: 時間外（日次＋週次、法定休日労働は含まない）を起算日（未設定なら給与期間初日）からの1か月で時系列に累計し、60時間を超えた部分。
6. **深夜**: 実時刻 22:00〜翌5:00。他区分と重複して加算。

> 週・月60時間の判定には、給与期間より前の週初・起算日からの勤務も入力に含める（期間をまたぐ週は時系列で超過した部分のみ当期に計上）。
> 「法定休日から翌日にまたがる勤務の翌日部分を始業日の1日8時間に含めるか」等の細部は **要専門家確認**。

## 4. 時給ルール（時給制）

- 種類: 基本／曜日別／時間帯別（営業日0:00からの経過で `22:00`〜`29:00` のように翌日表記）／祝日（店舗設定の祝日リスト。法定休日とは無関係）／特定日。
- 適用開始日・終了日、優先度。最も優先度の高いルールを採用。**同一優先度で時給の異なるルールが重なる場合は矛盾として確定禁止**（暫定計算は高い時給）。
- 「深夜割増を含む時給」の場合は割増算定基礎となる通常時給（`premiumBaseRate`）を必須とし、時給 ≥ 通常時給×1.25 を検証。深夜割増は別途加算しない。

## 5. 金額計算

### 5.1 時給制
- 基本賃金 = Σ（適用時給 × 労働時間）※全労働時間に100%
- 時間外割増 = Σ（算定基礎時給 × 時間外時間 × 25%）、月60時間超部分は 50%（25%ではなく50%）
- 法定休日割増 = Σ（算定基礎時給 × 休日労働時間 × 35%）
- 深夜割増 = Σ（算定基礎時給 × 深夜時間 × 25%）（深夜割増込み時給の区間を除く）
- 算定基礎時給 = 適用時給（深夜込みは `premiumBaseRate`）＋ 算入手当の時間単価（月額手当÷1か月平均所定労働時間、日額手当÷1日所定労働時間、時間給手当そのもの）。所定時間が未設定なら確定禁止。

### 5.2 月給制
- 基本給 = 月給（期間途中の入退社・月給変更は日割規定未確認として確定禁止。暦日按分で暫定表示）
- 時間単価 = （月給 ＋ 算入手当の時間単価換算）÷ 1か月平均所定労働時間
- 所定時間（公開済みシフトの予定実働、なければ所定曜日×1日所定時間）を超え法定時間内の労働 = 法定内残業 → 時間単価 × 設定率（100% or 125%、未設定は確定禁止）
- 法定時間外・法定休日労働は月給に含まれないため 100% 部分 ＋ 割増を支給（時間外125%／60h超150%／休日135%）。深夜は25%のみ加算。
- 固定残業代: 金額 ÷ 対象時間 ≥ 時間単価×1.25 を検証。実際の時間外賃金（100%部分＋割増）が固定額を超えた分を「固定残業代超過分」として支給。
- 欠勤控除・遅刻早退控除: **店長が承認した調整（PayrollAdjustment）のみ** を対象とし、規定（欠勤控除の除数日数等）が未設定なら確定禁止。シフトの遅刻・早退は自動控除しない。

### 5.3 有給休暇の賃金
- 算定方法（店舗設定）: 通常の賃金（時給×その日の所定労働時間）／平均賃金（直前3か月の確定給与から算出）／標準報酬日額（未対応→確定禁止）。未設定で取得がある場合は確定禁止。
- 月給制は基本給が継続支給されるため追加支給なし（欠勤控除対象外）。

### 5.4 手当・交通費
- 手当: 月額固定／出勤日額／時間額／変動（期間ごとに入力、未入力は確定禁止）。
- 割増算定基礎からの除外は労基則21条の7種（家族・通勤・別居・子女教育・住宅・臨時・1か月超）に限定。それ以外は必ず算入。
- 交通費: 未設定は確定禁止（「支給なし」の明示が必要）。日額×出勤日数／月額／実費（期間ごと入力）、上限あり。

### 5.5 控除
- 所得税・住民税・健康保険・介護保険・厚生年金・雇用保険・その他を手動入力。**未入力は確定禁止。「控除なし」を明示確定可能**。税率等からの自動計算・年末調整は対象外。
- 労使協定に基づく控除はフラグを立て、確定時に確認を求める。

### 5.6 最低賃金
- 店舗設定の地域別最低賃金（適用開始日付き、根拠メモ必須）。未設定は確定禁止。
- 時給制: 各区間の算定基礎時給（＋最低賃金算入の時間給手当）≥ 最低賃金。
- 月給制: （月給＋最低賃金算入の月額手当）÷ 1か月平均所定労働時間 ≥ 最低賃金。

## 6. 確定前チェック（severity）

| severity | 意味 | 例 |
|---|---|---|
| blocking | 解消しない限り確定不可 | 未設定の制度・法定休日・起算曜日・最低賃金・交通費・控除、打刻漏れ、未処理の修正、ルール矛盾 |
| confirm | 店長が個別に確認（acknowledge）すれば確定可 | 休憩不足、固定休憩適用、異常長時間、週44時間特例、労使協定控除 |
| info | 表示のみ | 36協定未締結、時給制への欠勤控除調整 |

## 7. 給与の状態と確定

`未集計 → 仮計算(draft) → 確認待ち(review) → 給与確定(confirmed) → 明細発行済み(issued)`

- 確定時に入力一式（勤怠セッション・給与条件・設定・計算バージョン・ルールセットID・内訳）をスナップショットとして保存。以後の時給変更で過去の確定結果は変わらない。
- 訂正は理由必須で新しいリビジョンを作成し、旧リビジョンは `superseded`。

## 8. 独立検証用の算出例（テスト期待値の根拠）

テストの期待値は実装関数の出力ではなく、本節のような手計算で算出する（`tests/unit/payroll.golden.test.ts`）。

## 9. 仕様の明確化（ゴールデンテスト作成時の指摘に基づく）

| 論点 | 決定 |
|---|---|
| `overtimeMinutes` と月60時間超 | `overtimeMinutes` は法定時間外の総時間（60時間超分を含む）。`over60Minutes` はその内数 |
| 固定残業代がある場合の時間外100%部分 | `extraHoursBasePay` には含めない（固定残業代と超過分に集約）。時間外割増も0として表示 |
| 法定内残業を125%で支払う場合 | 125%全体を `extraHoursBasePay` に計上（割増項目には計上しない） |
| 最低賃金違反 | blocking（確定不可） |
| confirm 系の課題 | `canConfirm` は blocking のみで判定。confirm 系は確定操作時に課題ごとの確認（acknowledge）を必須とし、未確認なら確定 API が拒否する |
| 交通費 | 総支給額に含める（課税・非課税の区分は控除の手動入力側で扱う） |
| 時給ルールの適用日 | 適用開始日・終了日、曜日、祝日、特定日はすべて **営業日** で判定（例: 営業日切替 05:00 なら 11/15 26:00 の勤務は 11/15 の時給） |
| 法定休日から翌日へまたぐ勤務の翌日部分 | 始業日の非休日労働として1日8時間判定に含める実装（**要専門家確認**） |
| 月給制の所定時間 | 公開シフトがあればその予定実働、なければ所定曜日×1日所定時間。1か月平均所定労働時間（時間単価算定用）とは独立に設定され、整合性は店長が確認する |
