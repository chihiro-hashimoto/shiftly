# 給与計算仕様（Shiftly）

> 本書は実装（`src/shared/payroll.ts` / `labor.ts` / `wage.ts` / `attendance.ts`）の仕様である。
> 法令解釈を含む箇所は **「要専門家確認」** と明記する。実際の給与規定は本番利用前に管理者および必要に応じて社会保険労務士等が確認すること。
> 法令の根拠は `docs/research/official-sources.md`（公式ドメインの検索結果に基づく。原文の再確認が必要）を参照。

## 1. 前提と対応範囲

| 項目 | 対応 |
|---|---|
| 労働時間制度 | **通常の労働時間制のみ**。変形労働時間制・フレックスタイム制を選択した場合は計算は表示するが **正式確定を禁止**（通常制へ暗黙にフォールバックしない） |
| 週の法定労働時間 | 40時間。週44時間特例は管理者が要件（常時10人未満・対象業種）を確認しフラグを立てた場合のみ。人数条件から自動適用しない |
| 36協定 | 記録のみ。未締結でも実労働時間・割増賃金は削減しない（情報として表示） |
| 計算単位 | 打刻はサーバー時刻（秒単位に切捨てて記録）。労働時間は **秒単位** で計算し、日々の切捨ては行わない |
| 端数処理 | 金額は有理数（BigInt 分数）で積算し、**項目ごとの期間合計で1回だけ** 円未満処理（既定: 50銭以上切上げ。設定で「切上げ」も可）。控除（欠勤・遅刻早退）は労働者に不利にならないよう円未満切捨て。30分単位の時間丸めは行わない |
| 法令ルールのバージョン | `LEGAL_RULESETS`（適用開始日付き）。現行 `JP-LSA-2023-04`: 時間外25%／月60h超50%／法定休日35%／深夜25% |

## 2. 日時の区別

| 概念 | 定義 | 用途 |
|---|---|---|
| 打刻日時 | サーバー受信時刻（UTC epoch ms、表示は Asia/Tokyo） | 原本 |
| 営業日 | 打刻時刻 −「営業日切替時刻」（既定 05:00）の暦日 | 表示・集計・時給ルールの曜日/祝日/時間帯判定 |
| 労働日 | **始業時刻（出勤打刻）の暦日**。日付をまたぐ連続勤務は始業日に属する | 1日8時間判定・週判定・給与期間への帰属 |
| 法定休日 | 店舗設定の曜日の **暦日 0:00〜24:00** | 休日労働判定 |
| 週 | 店舗設定の起算曜日から7日（労働日で判定） | 週40時間判定 |
| 給与計算期間 | 締め日設定から算出。労働日が期間内の勤務を当期に計上。直前月の期間が作成済みならその翌日から開始（締め日変更の移行期に重複・欠落を作らない）。他の期間と日付が重なる期間は作成・確定できない | 支給 |

## 2.5 シフト基準の給与対象時間（v1.3。`src/shared/worktime.ts`）

店舗設定 `payrollTimeBasis` が `shift`（既定）の場合、給与計算（2.〜6.の区分・金額計算）に渡す勤務を次のように作る。`actual` の場合は修正後の勤怠（C − D）をそのまま使う（v1.2 と同じ）。

| 区分 | 定義 | 保存・表示 |
|---|---|---|
| A 登録シフト時間 | 勤務と時間が重なる公開済みシフト（複数可）の和集合 | shifts |
| B 元の打刻時間 | 打刻原本（追記専用。書き換えない） | attendance_events |
| C 修正後の勤怠時間 | 原本＋反映済みの修正（本人修正・管理者修正） | attendance_corrections から再構築 |
| D 実際の休憩時間 | 休憩打刻・管理者登録の休憩・休憩申告（予定どおり／取得なし／実際の区間） | break_declarations ほか |
| E シフト外の勤務候補 | (C − D) − A。最初のシフトより前＝早出、最後のシフトより後＝残業、シフトの間、シフトなし＝シフト未登録 | 画面・`offshift.list` で表示 |
| F 申請・確認された実労働 | E のうち、承認（一部承認を含む）・管理者確認で実労働とされた区間の和集合 | overtime_requests（workConfirmation=work） |
| G 給与計算対象時間 | ((C − D) ∩ A) ∪ F | 給与計算の入力（スナップショットに保存） |

- 打刻がシフトより早い・遅いだけでは G を増やさない。E は実労働かどうかを確認する（申請・管理者の確認）。**申請がない・承認されていない・却下されたことだけを理由に、実労働を無給扱いにしない**（管理者は申請がなくても実労働を登録できる）
- E のうち未確認の時間が給与期間内にあるスタッフは、給与を確定できない（`OFF_SHIFT_UNCONFIRMED`: blocking）。未処理の申請（`OVERTIME_REQUEST_PENDING`: blocking）、差戻し中の申請（confirm）
- 解決の規則: 実労働＝承認・確認された区間の和集合／実労働なし＝判断済み（承認・却下（実労働なし）・確認済み）の申請区間のうち実労働でない部分（一部承認の残りを含む）／申請中・差戻し・取消・却下（実労働は未確認）は未確認のまま
- 同じ時間を複数の申請・確認で重ねても、区間の和集合で扱うため二重に加算しない
- 遅刻・早退: G は実際に働いた時間（シフト内でも勤務していない時間は含めない）。未勤務時間への支払・控除は既存の給与規定（月給制の欠勤・遅刻早退控除は承認分のみ）に従う
- 早出・残業という申請区分は、法定時間外労働（1日8時間・週40時間超）とは別。割増は G に対して 3. の区分で判定する（深夜・法定休日・月60時間超も同じ）
- 指揮命令下の準備・片付け・待機は労働時間（厚生労働省の解説）。「実労働なし」の確認は、本人への確認などで業務をしていなかったことを確かめた場合に限る（画面で注意を表示）
- 参考（公式）: https://www.check-roudou.mhlw.go.jp/qa/roudousya/roudoujikan/q5.html ／ https://www.check-roudou.mhlw.go.jp/study/roudousya_jikangai.html ／ https://www.mhlw.go.jp/bunya/roudoukijun/faq_kijyunhou_13.html ／ https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/koyou_roudou/roudoukijun/roudouzikan/070614-2.html（本セッションでは原文を再取得していない。法的判断は要専門家確認）
- 例（§9.2 の手計算。tests/integration/v13.test.ts・tests/unit/worktime.test.ts）: シフト 18:00〜23:00、打刻 17:55〜23:10、休憩なし → 仮 5:00（未確認 15 分で確定不可）／実労働なし確認 5:00／早出のみ 5:05／残業のみ 5:10／両方 5:15。時給 1,200 円で 5:15 は 6,300 円

## 2.6 休憩（v1.3。`src/shared/attendance.ts` `applyDeclarations`）

- シフトの予定休憩（休憩分数・開始時刻）は「予定どおり取得」と申告・確認された勤務にだけ控除する。申告がなければ控除しない（`PLANNED_BREAK_UNCONFIRMED`: confirm）。予定休憩の開始時刻が未登録なら控除しない（`PLANNED_BREAK_TIME_UNSET`: confirm）
- 申告: 退勤時（標準の予定休憩方式では退勤操作の中で確認）または勤怠確認画面から。取得なし（控除なし）／実際の休憩の区間（短縮・延長・時間帯違い・追加。打刻休憩より申告を優先し、矛盾は confirm）
- 二重控除の防止: 打刻・管理者登録の休憩がある勤務には予定休憩を重ねない。重なった休憩区間は統合
- シフトに休憩がない場合、法定休憩（6時間超45分・8時間超60分）を自動控除しない。不足は `INSUFFICIENT_BREAK`（confirm）で警告し、実労働に対する賃金は全額計算する
- 本人未確認（PIN 未設定）の申告: 「予定どおり」は反映し確認項目（`BREAK_DECLARED_UNVERIFIED`）、それ以外は承認待ち（`BREAK_DECLARATION_PENDING`: blocking）

## 3. 労働時間の区分アルゴリズム（`classifyLabor`）

1. 各勤務（退勤済み）の実労働区間（休憩を除く）を、暦日 0:00・5:00・22:00、時給ルールの時間帯境界、営業日境界で分割して「piece」にする。
2. piece の暦日が法定休日の曜日なら **法定休日労働**。（法定休日前日からの勤務が0時を越えた部分は休日労働、法定休日から翌日に越えた部分は休日労働ではない）
3. **1日単位の時間外**: 法定休日労働を除く piece を労働日ごとに時系列で累計し、8時間を超えた時刻以降。
4. **週単位の時間外**: 法定休日労働・1日単位の時間外を除く piece を週ごとに時系列で累計し、40時間（特例44時間）を超えた時刻以降（日次と週次の二重計上なし）。
5. **月60時間超**: 時間外（日次＋週次、法定休日労働は含まない）を起算日（未設定なら給与期間初日）からの1か月で時系列に累計し、60時間を超えた部分。
6. **深夜**: 実時刻 22:00〜翌5:00。他区分と重複して加算。

> 週・月60時間の判定には、給与期間より前の週初・起算日からの勤務も入力に含める（期間をまたぐ週は時系列で超過した部分のみ当期に計上）。60時間の起算日が週の途中にある場合は、その週の初日まで遡って読む（起算週の週次時間外を取りこぼさない。Codex 監査1 #5）。
> 「法定休日から翌日にまたがる勤務の翌日部分を始業日の1日8時間に含めるか」等の細部は **要専門家確認**。

## 4. 時給ルール（時給制）

- 種類: 基本／曜日別／時間帯別（営業日0:00からの経過で `22:00`〜`29:00` のように翌日表記）／祝日（店舗設定の祝日リスト。法定休日とは無関係）／特定日。
- 適用開始日・終了日、優先度。最も優先度の高いルールを採用。**同一優先度で時給の異なるルールが重なる場合は矛盾として確定禁止**（暫定計算は高い時給）。
- 「深夜割増を含む時給」の場合は割増算定基礎となる通常時給（`premiumBaseRate`）を必須とし、時給 ≥ 通常時給×1.25 を検証。深夜割増は別途加算しない。

## 5. 金額計算

### 5.1 時給制
- 基本賃金 = Σ（適用時給 × 労働時間）※全労働時間に100%
- 時間外割増 = Σ（算定基礎時給 × 時間外時間 × 25%）、月60時間超部分は 50%（25%ではなく50%）
- 法定休日割増 = Σ（算定基礎時給 × 休日労働時間 × 35%）
- 深夜割増 = Σ（算定基礎時給 × 深夜時間 × 25%）（深夜割増込み時給の区間を除く）
- 算定基礎時給 = 適用時給（深夜込みは `premiumBaseRate`）＋ 算入手当の時間単価（月額手当÷1か月平均所定労働時間、日額手当÷1日所定労働時間、時間給手当そのもの）。所定時間が未設定なら確定禁止。

### 5.2 月給制
- 基本給 = 月給（期間途中の入退社・月給変更は日割規定未確認として確定禁止。暦日按分で暫定表示）
- 時間単価 = （月給 ＋ 算入手当の時間単価換算）÷ 1か月平均所定労働時間
- 所定時間（公開済みシフトの予定実働、なければ所定曜日×1日所定時間）を超え法定時間内の労働 = 法定内残業 → 時間単価 × 設定率（100% or 125%、未設定は確定禁止）
- 法定時間外・法定休日労働は月給に含まれないため 100% 部分 ＋ 割増を支給（時間外125%／60h超150%／休日135%）。深夜は25%のみ加算。
- 固定残業代: 金額 ÷ 対象時間 ≥ 時間単価×1.25 を検証。実際の時間外賃金（100%部分＋割増）が固定額を超えた分を「固定残業代超過分」として支給。
- 欠勤控除・遅刻早退控除: **管理者が承認した調整（PayrollAdjustment）のみ** を対象とし、規定（欠勤控除の除数日数等）が未設定なら確定禁止。シフトの遅刻・早退は自動控除しない。

### 5.3 有給休暇の賃金
- 算定方法（店舗設定）: 通常の賃金（時給×その日の所定労働時間）／平均賃金（直前3か月の確定給与から算出）／標準報酬日額（未対応→確定禁止）。未設定で取得がある場合は確定禁止。
- 月給制は基本給が継続支給されるため追加支給なし（欠勤控除対象外）。

### 5.4 手当・交通費
- 手当: 月額固定／出勤日額／時間額／変動（期間ごとに入力、未入力は確定禁止）。
- 割増算定基礎からの除外は労基則21条の7種（家族・通勤・別居・子女教育・住宅・臨時・1か月超）に限定。それ以外は必ず算入。
- 交通費: 未設定は確定禁止（「支給なし」の明示が必要）。日額×出勤日数／月額／実費（期間ごと入力）、上限あり。

### 5.5 控除
- 所得税・住民税・健康保険・介護保険・厚生年金・雇用保険・その他を手動入力。**未入力は確定禁止。「控除なし」を明示確定可能**。税率等からの自動計算・年末調整は対象外。
- 労使協定に基づく控除はフラグを立て、確定時に確認を求める。

### 5.6 最低賃金
- 店舗設定の地域別最低賃金（適用開始日付き、根拠メモ必須）。未設定は確定禁止。
- 時給制: 各区間の算定基礎時給（＋最低賃金算入の時間給手当）≥ 最低賃金。
- 月給制: （月給＋最低賃金算入の月額手当）÷ 1か月平均所定労働時間 ≥ 最低賃金。

## 6. 確定前チェック（severity）

| severity | 意味 | 例 |
|---|---|---|
| blocking | 解消しない限り確定不可 | 未設定の制度・法定休日・起算曜日・最低賃金・交通費・控除、打刻漏れ、未処理（承認待ち）の修正（期間内）、ルール矛盾、月給制で算入手当が期間途中に変更（`ALLOWANCE_CHANGED_MID_PERIOD`）、v1.3: 未確認のシフト外時間（`OFF_SHIFT_UNCONFIRMED`）・未処理の早出残業申請・承認待ちの休憩申告 |
| confirm | 管理者が個別に確認（acknowledge）すれば確定可 | 休憩不足、異常長時間、週44時間特例、労使協定控除、v1.3: 予定休憩の取得未確認・本人修正（管理者未確認）・本人未確認の休憩申告・休憩申告と打刻の矛盾・差戻し中の申請 |
| info | 表示のみ | 36協定未締結、時給制への欠勤控除調整、深夜割増込み時給の差額支給（`NIGHT_INCLUDED_TOPUP`） |

- 期間の終了前（期間末日の翌日の営業日切替時刻より前）は正式確定できない（Codex 監査1 #3）

## 7. 給与の状態と確定

`未集計 → 仮計算(draft) → 確認待ち(review) → 給与確定(confirmed) → 明細発行済み(issued)`

- 確定時に入力一式（給与計算対象の勤怠セッション・時間区分（v1.3: timeBasis）・給与条件・設定・計算バージョン・ルールセットID・内訳）をスナップショットとして保存。以後の時給変更・勤怠修正・申請の承認で過去の確定結果は変わらない（確定後の修正・承認は給与の訂正で反映）。
- 訂正は理由必須で新しいリビジョンを作成し、旧リビジョンは `superseded`。

## 8. 独立検証用の算出例（テスト期待値の根拠）

## 9. 仕様の明確化（ゴールデンテスト作成時の指摘に基づく）

| 論点 | 決定 |
|---|---|
| `overtimeMinutes` と月60時間超 | `overtimeMinutes` は法定時間外の総時間（60時間超分を含む）。`over60Minutes` はその内数 |
| 固定残業代がある場合の時間外100%部分 | `extraHoursBasePay` には含めない（固定残業代と超過分に集約）。時間外割増も0として表示 |
| 法定内残業を125%で支払う場合 | 125%全体を `extraHoursBasePay` に計上（割増項目には計上しない） |
| 最低賃金違反 | blocking（確定不可） |
| confirm 系の課題 | `canConfirm` は blocking のみで判定。confirm 系は確定操作時に課題ごとの確認（acknowledge）を必須とし、未確認なら確定 API が拒否する |
| 交通費 | 総支給額に含める（課税・非課税の区分は控除の手動入力側で扱う） |
| 時給ルールの適用日 | 適用開始日・終了日、曜日、祝日、特定日はすべて **営業日** で判定（例: 営業日切替 05:00 なら 11/15 26:00 の勤務は 11/15 の時給） |
| 法定休日から翌日へまたぐ勤務の翌日部分 | 始業日の非休日労働として1日8時間判定に含める実装（**要専門家確認**） |
| 割増算定基礎・最低賃金に算入する手当の適用日 | 時給制は**労働日**ごとに有効な手当のみ（手当の支給判定と同じ基準。Codex 監査1 #7） |
| 深夜割増込み時給と算入手当の併用 | 時給に含まれる割増額（込み時給 − 算定基礎時給）が、手当を含む算定基礎 × 25% に満たない場合は差額を深夜割増として支給（Codex 監査1 #6） |
| 月給制の所定時間 | 公開シフトがあればその予定実働、なければ所定曜日×1日所定時間。1か月平均所定労働時間（時間単価算定用）とは独立に設定され、整合性は管理者が確認する |
